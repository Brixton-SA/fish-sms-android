# Fish SMS — reglas para agentes

- **Marca: NUNCA un pez.** El ícono, la pantalla principal y cualquier imagen de la app usan SIEMPRE el logo oficial de Fish (`client/public/icon-512.png` del repo fish-system). Prohibido dibujar un pez, usar emoji 🐟 o íconos genéricos como logo. Si hace falta otro tamaño, se genera desde ese archivo; nunca se inventa.
- Textos en español rioplatense, positivos, sin emojis.
- No compilar en la Mac del owner: el build lo hace GitHub Actions (`build.yml` en main, `release.yml` con tags `v*`).
